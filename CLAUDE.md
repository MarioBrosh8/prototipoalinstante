# Pro-In: notas para agentes

- Astro 7 static output, served by a Worker with static assets only (no script). Custom domains `prototipoalinstante.com` (canonical) and the original `prototipoalinstante.mariovaldez.dev` via `routes` in `wrangler.jsonc`; `www.prototipoalinstante.com` is a separate one-file redirect Worker in `workers/www-redirect/` (`npm run deploy:www`), so the main Worker stays script-free. No `account_id` in config (public repo; wrangler uses the OAuth session or `CLOUDFLARE_ACCOUNT_ID`).
- Client JS lives in `src/scripts/*.ts` and is imported only from `src/scripts/main.ts`. Do not add `<script>` blocks to components: Astro inlines small import-free scripts, and the CSP in `public/_headers` (`script-src 'self'`) blocks inline JS in production. `vite.build.assetsInlineLimit: 0` keeps chunks external.
- The CSP allows `static.cloudflareinsights.com` (script) and `cloudflareinsights.com` (connect) because the mariovaldez.dev zone auto-injects Cloudflare Web Analytics; nothing else external.
- three.js is only in `src/scripts/printer3d.ts`, loaded with a dynamic import from `hero.ts` after `load` + idle. Import named classes only. The loop pauses offscreen and in hidden tabs. Reduced motion shows the finished, lit lamp with no spin.
- Photos go through `src/components/Photo.astro` (one AVIF/WebP encode per photo, max 900 px) so the same photo in several sections is one request. The `mariovaldez.dev` zone rate-limits bursts per IP on every subdomain: keep first-load requests low.
- Copy is es-MX with zero em or en dashes. Prices, payments and delivery facts come from Pro-In's Instagram "Cotizaciones" post plus their 2026-10-05 changes (design paid with the deposit, 2 free revisions, shipping to all of Mexico); don't invent claims. The brand is written "Pro-In". CTA label for quotes is always "Cotiza tu idea" (`cta.contact` in `src/data/site.ts`); every one of those buttons goes to the questionnaire (`site.quote`, `#cotiza`), not to the DM, and composer.ts turns long trips there into a short glide plus a ring on the first question. Instagram links all say "Ver Instagram" (`cta.instagram`). The violet "¿Lo imprimimos?" band sits right above the questionnaire, so it introduces it and has no quote button. The one exception is the composer's send area: Instagram can't prefill a DM (`ig.me` only takes `?ref=`), so it shows two literal steps, "Copia tu mensaje" and "Abre el chat y pégalo", and the second one also copies if the first was skipped.
- Palette: one accent (Pro-In violet `#8a3bc1`); the logo keeps its own measured colors (`--logo-ink`, `--logo-light`, `--logo-green`). Tokens use `light-dark()` in `src/styles/global.css`; the page follows the system theme, the 3D chamber stays dark in both.
- `[hidden]` is forced to `display: none !important` globally; component `display` rules would otherwise un-hide things.
- Do not write `\u` escapes through the editor tools (they land as literal characters).
- Dev server port 4324 (`npm run dev`), production-like preview on 8791 (`npm run preview`, wrangler dev). Stop `astro dev` before `astro build`, or Vite's deps cache can break.
- `?shot=<section id>` (dev only) renders that section at the top for headless screenshots.
- Logos: `src/data/logo.ts` holds the vectors (generated once from Pro-In's files; the full logo reuses the mark through `place`). `Logo.astro` animates with a mask of centerline pieces (`drawPieces`) plus a seal rect; below the fold it waits for `.is-in` via `[data-draw]` in `initReveals()`. The footer credit is Daku (`DakuLogo.astro`, links to daku.com.mx; daku.mx does not resolve).
- Motion: easing tokens `--ease-out`, `--ease-in-out`, `--ease-drawer`; press feedback `scale(var(--press))` (0.97) on text buttons and `scale(var(--press-icon))` (0.94) on small icon buttons, both over `var(--dur-press)`. Hover motion only inside `(hover: hover) and (pointer: fine)`. Animate transform and opacity; layout changes slide with FLIP (see categories.ts). Every movement needs a `prefers-reduced-motion` path.
- Email: Cloudflare Email Routing forwards `contacto@prototipoalinstante.com` to `prototipoalinstante@gmail.com`; replies go out from Gmail through Cloudflare Email Sending SMTP (`smtp.mx.cloudflare.net:465`, user `api_token`). The zone has DMARC `p=reject`, so anything sending as @prototipoalinstante.com must go through Email Sending (Gmail's own SMTP would be rejected). Manage with `wrangler email routing ...` / `wrangler email sending ...`.
